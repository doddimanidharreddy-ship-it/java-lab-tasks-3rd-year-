# Java Problem Solving Programs 🚀

A collection of well-commented Java programs covering fundamental programming topics.

## 📚 Topics Covered

| # | File | Topic | Concept |
|---|------|-------|---------|
| 1 | `PrintArray.java` | Print Array Elements | `for` loop, indexing |
| 2 | `MaxMinArray.java` | Max & Min in Array | Comparison logic |
| 3 | `LinearSearch.java` | Linear Search | Sequential search O(n) |
| 4 | `BinarySearch.java` | Binary Search | Divide & conquer O(log n) |
| 5 | `BubbleSort.java` | Bubble Sort | Adjacent swapping O(n²) |
| 6 | `SelectionSort.java` | Selection Sort | Min selection O(n²) |
| 7 | `InsertionSort.java` | Insertion Sort | Key insertion O(n²) |
| 8 | `Factorial.java` | Factorial | Recursion |
| 9 | `Fibonacci.java` | Fibonacci Series | Iteration |
| 10 | `PrimeNumber.java` | Prime Number Check | Math.sqrt optimization |
| 11 | `ReverseString.java` | Reverse a String | StringBuilder |
| 12 | `Palindrome.java` | Palindrome Check | Two pointer technique |
| 13 | `Stack.java` | Stack Implementation | Array-based LIFO |
| 14 | `LinkedList.java` | Linked List | Node pointers |
| 15 | `Student.java` | OOP Concepts | Class, Object, Constructor |

## 🛠️ How to Run

```bash
# Compile
javac FileName.java

# Run
java FileName
```
